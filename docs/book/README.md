# Cookbook editions

The canonical cookbook is [`../firstpair-lightroom-repair.md`](../firstpair-lightroom-repair.md). The root [`book.build.json`](../../book.build.json) drives the shared FirstPair builder. [`../../FIRSTPAIR.md`](../../FIRSTPAIR.md) records source ownership, clean/pushed provenance, verification and full-edition publication commands.

PDF, EPUB, single-file HTML, split chapter HTML and the version manifest are generated in the repository's `dist/`. These are complete cookbook editions, distinct from the blog story and its TextPack. Reader styling and the export-only source-link filter live here; the filter does not modify the manuscript.
